================================================================================
                          COMMON ERRORS & FIXES
================================================================================

405 Method Not Allowed
- /projects/ (GET) → Use /projects/my/ instead
- /projects/ (POST) → Correct endpoint

404 Not Found
- /audit-logs/ → Should be /audit/admin/audit-logs/
- /portfolio/ → Should be /investments/portfolio/summary/
- /projects/pending/ → Should be /projects/admin/projects/pending/

403 Forbidden
- Missing or invalid Authorization header
- Solution: Include "Authorization: Bearer <token>" in all protected requests

400 Bad Request
- Missing required fields in request body
- Check serializer requirements in API documentation

================================================================================
                         AUTHENTICATION REQUIRED
================================================================================

The following endpoints require Authorization header:
- All endpoints EXCEPT:
  - POST /auth/register/
  - POST /auth/login/
  - POST /auth/refresh/
  - POST /auth/verify-email/
  - GET /projects/ (list)
  - GET /projects/<id>/ (detail)
  - GET /projects/browse/
  - POST /projects/compare/
  - GET /projects/<id>/detail/

Header format:
Authorization: Bearer <access_token>

How to get token:
1. POST /auth/login/ with email and password
2. Response includes "access" token
3. Store in localStorage: localStorage.setItem('access_token', token)
4. Include in all protected requests
